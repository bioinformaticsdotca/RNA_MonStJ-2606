Gene Ontology Enrichment with clusterProfiler

clusterProfiler requires Entrez Gene IDs.

GO Biological Process Enrichment

ego_bp = enrichGO(
  gene          = rownames(deg),
  OrgDb         = org.Hs.eg.db,
  keyType       = "ENTREZID",
  ont           = "BP",
  pAdjustMethod = "BH",
  pvalueCutoff  = 0.05,
  qvalueCutoff  = 0.05,
  readable      = TRUE
)
